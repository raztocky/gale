Brickle Browser

A browser engine written from scratch in Rust. No Chromium, no WebKit, no Gecko.

What works

  • HTML parsing with implicit tags, entities & raw text
  • CSS selectors, specificity, the cascade and inheritance
  • Block & inline layout, text wrapping, max-width, auto margins
  • Lists, borders, backgrounds, underline, strikethrough

Try it

  1. Press Ctrl+L or click the address bar, type a URL, hit Enter.
  2. Click links. Backspace goes back. 
cargo run --release -- https://example.com
cargo run --release -- render page.html -o page.png
